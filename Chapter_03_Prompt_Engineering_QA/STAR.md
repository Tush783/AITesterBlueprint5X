# STAR

## Situation
I am a QA engineer preparing to test the login at [app.wingify.com](https://app.wingify.com/#/login) for this exercise. Assume the approved requirements are:

- Registerd Users can log in with valid credentials
- Invalid Credentials must not grant access and give error. 
- Email And passwords are mandatory.
- Successful login opens the authenticated dashboard.
- Invalid login gives error message "Your email, password, IP address or location did not match"

## Task
- Create a functional test plan for the login module. Use the template here - Chapter_03_Prompt_Engineering_QA/Test Plan - Template.docx.pdf

## Action
Define the objectives, scope, and testing approach.

Cover valid login, invalid credentials, empty fields, and access to the dashboard after login.

Include positive, negative, and boundary scenarios where supplied requirements support them.

Define test environment needs, test data, entry criteria, exit criteria, deliverables, and risks.

Mark unspecified behaviour as  "Requires Clarification." Do not invent password rules, exact error messages, or session timeouts.

## Result
Return a test plan containing:
Test Plan ID and Title
Objective
In scope and out of scope
Test Appproch
Test Scenarios
Environment and Test Data
Entry and Exit Criteria
Deliverables
Risks and Open Questions

Use clear language and tables wher useful.Label any proposed criteria as recommendations.
